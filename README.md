# Stroke Prediction Using Logistic Regression

## Overview
This project aims to predict stroke risk using demographic and clinical features through Logistic Regression.

## Objective
To identify individuals at higher risk of stroke and support healthcare decision-making using statistical modeling.

## Tools & Technologies
- R Programming
- Logistic Regression
- Exploratory Data Analysis (EDA)
- ROC-AUC Analysis
- Data Visualization

## Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Logistic Regression Model Building
5. Model Evaluation

## Evaluation Metrics
- Accuracy
- Confusion Matrix
- ROC Curve
- AUC Score

## Results
The model identified significant factors associated with stroke risk and demonstrated predictive capability through ROC-AUC evaluation.
